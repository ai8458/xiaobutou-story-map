## 临摹与打印

先画标题和 8 个场景，再连接箭头、填写标注，最后淡淡上色。故事路线从上排左侧开始，向右走，再沿下排向左走。

打印 PDF 时选择 **A4、横向、实际大小（100%）**。地图按故事主线概括，场景位置为示意，不代表实际地理比例。

原著：孙幼军《小布头奇遇记》。此图为阅读活动制作的场景示意。
